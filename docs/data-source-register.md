# Data-Source Register: OmniChannel Retail Platform

This register documents the core data sources feeding the retail big-data architecture, establishing grain, structure, arrival patterns, quality risks, sensitivity levels, and ingestion methods.

| Field / Source | 1. Clickstream & Web Events | 2. Operational Orders & Inventory | 3. Customer Support & CRM |
| :--- | :--- | :--- | :--- |
| **Producer & Purpose** | Web frontend & mobile app user tracking; captures user navigation, product views, and cart additions for real-time personalization and traffic analysis. | Core relational database (`RetailDB_Advanced`); records finalized customer orders, items, payments, and fulfillment updates. | External CRM and customer support ticketing system; records customer profiles, support cases, and satisfaction ratings. |
| **Record Grain** | One row per user web event (click, page view, cart action). Includes exact timestamp (`event_timestamp`) and session/user IDs. | One row per order line item. Includes order ID, product ID, customer ID, timestamp, and status. | One row per customer profile or support ticket interaction. Includes customer ID, ticket ID, and status. |
| **Structure & Format** | Semi-structured JSON event streams. | Structured relational rows (exported as Parquet/CSV micro-batches). | Structured and semi-structured CSV/JSON files. |
| **Arrival & Scale** | Continuous event stream via message broker. Typical rate: 500 events/sec; Peak rate: 2,500 events/sec. High volume (~50 GB/day). Retention: 3 years. | Micro-batches and Change Data Capture (CDC) every 15 minutes, plus daily full snapshots. ~10 GB/day. Retention: Indefinite (historical). | Daily batch files dropped at midnight via secure file transfer (SFTP). ~2 GB/day. Retention: 5 years. |
| **Quality Risks** | Missing session IDs, duplicate event emissions due to network retries, out-of-order event arrivals, schema drift. | Missing foreign keys, concurrent transaction locks, duplicate transaction IDs on retry. | Outdated customer contact info, unstructured free-text fields with typos, unmapped customer IDs. |
| **Sensitivity & Ownership** | **Owner:** Web Product Team. **Classification:** Internal / Low Personal Risk (IP addresses, cookie tokens). | **Owner:** Order Management Team. **Classification:** Restricted Commercial & Personal (Shipping addresses, order amounts). | **Owner:** Customer Success Team. **Classification:** Highly Restricted Personal (Names, emails, support communications, GDPR-governed). |
| **Acquisition Method** | Kafka-compatible event streaming topic landing directly into Cloud Object Storage (Raw Zone). | Change Data Capture (CDC) pipeline / scheduled micro-batch loader via secure API. | Secure scheduled file transfer (SFTP) into Object Storage Raw Zone. |
